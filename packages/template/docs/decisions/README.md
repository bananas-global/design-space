# Decisões deste produto

Registros curtos de decisão e consequência, **específicos deste produto**:
identidade visual, regra de negócio, recorte de escopo, divergência com o sistema
real.

## O que **não** vem para cá

As decisões do modelo — fixture sintética como padrão, preview público, escopo do
source mapping, ação bloqueada que explica o motivo, acessibilidade obrigatória no
contrato de cenário — valem para todos os Design Spaces e vivem uma única vez, no
repositório do motor:

<https://github.com/bananas-global/design-space/tree/main/docs/decisions>

Duplicar aqui cria duas fontes que divergem na primeira vez que uma for atualizada.
Se você discorda de uma decisão do modelo, o lugar de mudar é lá — ou registre aqui
a **exceção** deste produto, dizendo qual decisão do modelo ela abre e por quê.

## Formato

Um arquivo por decisão, numerado, com: contexto, decisão, consequências e a
alternativa descartada. Curto é melhor que completo — o objetivo é que alguém em
seis meses entenda por que a coisa é assim, não reconstituir a discussão.
